# Lian Vocal MIX JP Standalone V3 — Click UI

- 긴 세로 스크롤 대신 PORTFOLIO / PRICE / GUIDE / REVIEWS / CONTACT 클릭 전환
- 선택한 탭만 연한 블루·라벤더보다 한 단계 진하게 표시
- PORTFOLIO: SOLO / DUET / GROUP 클릭 전환
- PRICE: LIGHT / STANDARD / DELUXE 클릭 전환
- GUIDE: 의뢰 흐름 / 필요 파일 / 납기·주의사항 클릭 전환
- CONTACT: X DM은 바로 보이고, 웹폼은 클릭 시에만 펼쳐짐
- 기존 Netlify Form / Gmail / Naver / Kakao / 견적 계산 기능 유지
